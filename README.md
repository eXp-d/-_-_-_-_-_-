# Сбор данных: аэропорты, выборы, цены

Три учебных задания на сбор данных. Инструменты: `selenium`, `beautifulsoup4`, `re`.
Для каждого задания свой скрипт.

## Установка
    pip install -r requirements.txt
Нужен Google Chrome или Яндекс Браузер (драйвер подбирается отдельно, см. ниже).

---

## 1. Аэропорты мира
Скрипт: `scrape_airports.py` (скрапер ourairports.com), запасной вариант: `build_dataset.py`
(скачивает готовые csv OurAirports, весь мир: ~86 тыс. аэропортов, ~48 тыс. полос).

    python scrape_airports.py FI --limit 10      # страна, лимит для теста

Поля: ICAO, широта, долгота, статус (open/close), тип, страна, высота (фут),
часовой пояс, количество и параметры полос (ID, длина в футах, покрытие).
Форматы: csv, json, toml, yaml (папки `output/`, `output_scraped/`).

Примечания: часовой пояс на сайте не указан, считается по координатам
(`timezonefinder`), целым числом часов.

---

## 2. Выборы: протоколы УИК по федеральному округу
Скрипт: `scrape_elections.py`. Сайт izbirkom.ru, выборы в Госдуму IX созыва (2026).
Одна запись = один УИК, строки протокола 1-22, иерархия ИКСРФ / ОИК / ТИК / УИК,
федеральный округ.

    python scrape_elections.py --browser yandex --driver chromedriver.exe
    python scrape_elections.py --path "город Москва / Тушинский / Хорошево-Мневники"

Результат: `output_elections/uik_protocols.csv`, `legend.csv` (смысл строк).

Особенности:
- часть чисел в таблице на сайте подменена (в ячейке невидимый мусорный текст,
  настоящее значение лежит в наложенной ячейке) - скрапер читает то, что видит человек;
- номера строк берутся по порядку, т.к. на сайте они искажены;
- контрольные суммы: голоса за партии = строка 10; строки 7+8 = 9+10; колонка `check_ok`;
- сайт ограничивает автоматический показ протоколов, поэтому скрипт делает паузы,
  повторы и перезапускает браузер каждые 5 УИК;
- собран образец (часть ТИК Хорошево-Мневники), не вся страна: около 95 тыс. УИК
  слишком много для учебного сбора.

Драйвер: `get_chromedriver.py 152` скачивает chromedriver нужной версии.

## 3. Инфляция: цены на продукты
Скрипт: `scrape_prices.py`, список товаров: `products.toml`
(категория -> группа -> ссылка). Магазин: Пятёрочка (5ka.ru).

    python scrape_prices.py --setup --browser yandex    # один раз: выбрать магазин
    python scrape_prices.py --visible --browser yandex  # сбор раз в неделю

Результат: `output_prices/prices.csv`: `n, date, <товар за кг/л>..., basket_total, basket_ok`.
Лимит корзины: 1/4 МРОТ ±5% (МРОТ Москвы 2026: 39 730 ₽). Запуск раз в неделю
настраивается через планировщик задач Windows.

Статус: список товаров небольшой, корзина пока не доведена до лимита
(нужно добавить группы товаров в `products.toml`).
